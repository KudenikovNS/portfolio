# Nikita Kudenikov — Portfolio

Personal portfolio website of Nikita Kudenikov, Full-stack developer.

**Live:** https://kudenikovns.github.io/portfolio

## Getting started

```bash
npx yarn@1 install   # install dependencies
npx yarn@1 start     # dev server at http://localhost:3000/portfolio
npx yarn@1 build     # production build into ./build
npx yarn@1 deploy    # build and publish to GitHub Pages (gh-pages branch)
```
